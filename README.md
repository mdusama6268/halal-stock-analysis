# Halal Stock Analysis 📊

A Python-based investment research project designed to analyze and monitor Shariah-compliant stocks using market and financial data.

## 🎯 Project Objective

The project was created to simplify research and analysis of potential Shariah-compliant investment opportunities using Python-based data processing and an accessible Google Sheets dashboard.

## 🚀 Features

- Python-based stock analysis
- Shariah-focused investment research
- Stock performance monitoring
- Fundamental and market-data analysis
- Automated data processing
- Google Sheets reporting/dashboard
- Portfolio and investment research workflow

## 🛠 Tech Stack

- Python
- Pandas
- Google Colab
- Google Sheets
- Financial Data APIs
- Data Analysis & Automation

## 📓 Run / View the Project

The complete Python notebook is available in this repository:

`notebooks/halal_stock_analysis.ipynb`

The notebook can also be opened directly in Google Colab using the **Open in Colab** link available with the notebook.
